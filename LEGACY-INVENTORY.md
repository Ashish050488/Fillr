# JobFill 1.0.1 behavior inventory (migration reference)

This inventory describes implementation, not promises in the README or changelog. The legacy source remains in place until replacement is tested.

## Surfaces and features

- **Manifest:** MV3 module service worker; popup, options, content script on HTTP(S), storage/unlimitedStorage/activeTab/scripting; host permissions for Gemini, Groq and OpenRouter; four packaged icon sizes.
- **Shared utilities:** local/sync storage callback wrappers; version-1 legacy history migration; isolated jobs and lifetime counters; sync backup of up to 40 compact jobs in metadata and 15-job chunks; restore discovery; masked keys, file-size formatter and toast. Defaults for settings, AI routing, profiles and lifetime counters.
- **Background AI:** Gemini, Groq and OpenRouter completion calls; persisted per-provider round-robin cursor and key usage; three-minute cooldown on 429/5xx/network/timeout; invalidation on 401/403 or Google's 400 invalid-key text; provider fallback; JSON fence stripping and one repair attempt; per-call 30-second abort; single-key test; provider model discovery (Gemini generateContent filter, Groq models, OpenRouter free suffix filter).
- **Background tracker:** records fills and counts, marks jobs applied, logs tailoring without incrementing fill counts; initializes on install/startup, opens onboarding on fresh install.
- **Content:** one-time injection guard, nested open shadow-root and same-origin iframe traversal for fields; label/name/id/placeholder/aria/autocomplete matching; fills common identity/contact/location/employment/compensation fields, resume file, select, with native setter and events; skips uncertain controls; popup-triggered fill/detect/tailor; auto mode and mutation observer; floating fill summary and manual Applied prompt; job description extraction; textarea Tailor modal with tone/length/note, editable draft, regeneration, copy, insert and match check. Never submits a form.
- **Popup:** active profile switcher, site/field detection badge, fill and tailor actions, one-time reinjection for old tabs, auto-fill toggle, lifetime and recent applied counts, navigation to dashboard, settings and keys; theme override.
- **Options:** profile create/switch/rename/delete; editable scalar fields with provenance, skills, experience, education and project lists; PDF drop/upload/text extraction and AI parse; re-parse, single/batch AI field suggestion and confirm-all; key add/remove/test, routing, models and fallback configuration; test prompt; dashboard counts, week bars, streak, search/filter, job add/edit/status/delete, JSON/CSV export/import, sync restore and backup reminder; auto-fill/site/theme/tone/length settings and reset.
- **Onboarding:** three illustrated steps with next/back and finish link to AI Keys; completion boolean only on finish.
- **PDF:** locally packaged pdf.js worker; page-by-page positional text extraction, scanned heuristic (<40 non-whitespace characters), FileReader ArrayBuffer and data URL helpers. PDF only; DOCX not supported.

## Existing messages (wire shape)

All legacy messages use `{ action, payload? }`, callback replies, without runtime payload validation. Background receives `GET_STATUS` → `{status:'ready',version}`; `ASK_AI` → `{success,data?,text?,providerUsed?,keyUsedMasked?,modelUsed?,error?}` (payload `task,system,prompt,json`); `TEST_SINGLE_KEY` → `{valid,message?|error?}` (payload `provider,key,model`); `FETCH_MODELS` → `{success,models?|error?}` (payload `provider,key,freeOnly`); `RECORD_FORM_FILL` → `{success,jobId}` (payload `site,url,jobTitle,company,fieldsFilled`); `MARK_JOB_APPLIED` → `{success}` (payload `jobId?,site,url,jobTitle,company`); `LOG_APPLICATION_EVENT` → `{success}` (payload `site,jobTitle,company,fieldsFilled,type`). Content receives `PING` → `{status:'pong',url}`; `DETECT_FORM` → `{found,inputCount}`; `FILL_FORM` → `{success,filledCount?,totalCount?,skippedFields?,message?}`; `TRIGGER_TAILOR_LAST_CLICKED` → `{success,message?}`. Popup sends the last three content actions except PING; options and content send AI/tracker actions. There is no legacy `TRIGGER_TAILOR` action; the requested typed name should alias/replace the last-clicked action without breaking existing interactions.

## Storage compatibility contract

Local keys: `jobfill_profiles` (array of `{id,name,isDefault,resume:{fileName,fileSize,fileType,uploadDate,base64,plainText},fields:{fieldName:{value,source,confirmed}},skills,certifications,languages,workExperience,education,projects}`), `jobfill_active_profile_id` (string), `jobfill_ai_config` (`providers.{gemini,groq,openrouter}.{keys,model}` with Gemini `parsingModel`, `taskRouting` with `{provider,useGemma}`, `useBackupProviders`), `jobfill_key_usage_logs` (key-hash map of date/callsToday/status/cooldownUntil/lastError), `jobfill_settings` (booleans, site arrays, provider/tone/length/theme), `jobfill_stats` (legacy mirror), `jobfill_onboarding_completed` (boolean), `jobfill_application_history` (legacy array), `jobfill_job_desc_cache`, `jobfill_data_version` (number, currently 1), `jobfill_jobs_v1` (job array with id/company/jobTitle/url/site/date/timestamp/status/notes/fieldsFilled), `jobfill_lifetime_metrics_v1` (`totalFormsFilled,totalJobsApplied,totalFieldsFilled,timeSavedMinutes`), `jobfill_last_backup_reminder` (timestamp), `jobfill_round_robin_state` (provider cursor map). Sync keys: `jobfill_sync_backup_v1` (old backup), `jobfill_sync_backup_meta` (`savedAt,metrics,chunkCount,totalBackedUpJobs`), and `jobfill_sync_backup_jobs_0` etc. Preserve unknown properties on existing records where possible; never reset jobs or counters during migrations.

## Confirmed legacy defects to correct

1. `DEFAULT_STATS` is imported but not exported, so the module service worker and popup/options modules fail to load. This makes the advertised release unusable.
2. Options declares `exportAllDataBtn` and `importAllDataInput` twice in the same scope, causing a syntax error; the two duplicate handlers also disagree on backup format and export API keys by default.
3. Profile deletion filters its in-memory array but `saveCurrentProfileToStorage()` only writes when the new active profile exists, without intentionally guarding history; there is only one confirmation. Keys and resume deletion also lack the requested two confirmations.
4. Storage wrappers ignore `runtime.lastError` except sync writes; sync backup swallows errors. Fixed-size chunks can exceed 7 KB with multibyte strings and old extra chunk keys persist. Initializing empty local history can overwrite a recoverable sync backup before offering restore.
5. AI logs ignore `error_logged`, leaving last error invisible; 400/404 model failures continue through every key, and JSON repair exceptions are caught as network errors, cooling a healthy key. Gemini non-Gemma sends fake conversation turns instead of `systemInstruction`.
6. Plain-text `ASK_AI` can be sent from content with arbitrary payload; key plaintext travels from options to background in test/discovery messages. New bridge must authorize callers, resolve saved keys inside the worker and validate every payload.
7. Filling records a job even when zero fields were filled; callback errors are swallowed. The Applied button claims success before the response and can increment the lifetime counter repeatedly even when a job is already Applied. Auto mode can repeatedly fill and log on mutations; allowlist is not enforced. Country selects claim success when no option matched.
8. Content injection UI is in the page DOM, not a Shadow DOM; `innerHTML` on page-adjacent UI and untrusted job URLs need hardening. Existing matcher does not fill contenteditable, radio or checkbox safely and does not test field matching against ATS fixtures.
9. Readme/changelog claim DOCX, match percentage, monthly reminders and robust imports beyond actual behavior; README also claims resume never leaves browser despite AI prompts sending its text to chosen providers. CSV import splits on commas rather than parsing quoted CSV; imports lack schema validation or preview. Inline edit counters miss some status transitions; recent-job date is used as application date.
